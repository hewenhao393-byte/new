# CatBoost43 V3 正式部署模型来源与使用边界

## 模型用途

本目录中的 CH3、CH4、CH5 三个 CatBoost 模型是水泵故障诊断软件 V3 的正式部署模型，仅用于软件推理。三个模型分别接收 CH3、CH4、CH5 的 43 维特征，不共享单通道模型。

## 训练数据与参数

- 来源：`file_split/features_ch3.csv`、`features_ch4.csv`、`features_ch5.csv`。
- 范围：每个通道使用全部验收合格数据，各 108,855 个窗口、1,845 条记录。
- 特征：固定 43 维、固定顺序，未加入标准化器或缺失值填充器。
- 参数：固定 P1@500（`iterations=500`、`depth=8`、`learning_rate=0.05`、`l2_leaf_reg=100`、`random_strength=5`、`rsm=0.7`、`auto_class_weights=SqrtBalanced`、`random_seed=2026`）。P1@500 是在预先定义的候选范围内选定的参数，不声称是全局最优参数。

精确的数据源绝对路径、源文件 SHA-256、模型 SHA-256、类别顺序、样本数和类别分布见 `models/catboost43_v3/manifest.json`。

## 评价边界

正式部署模型使用全部验收合格数据重新训练，因此没有为这三个模型保留独立测试集，也不声称持有部署模型的泛化性能。

原有 `parent_group` 严格泛化评价结果、对应评估模型及 manifest 保持不变。它们不是本部署目录的模型，其性能不能被重新表述为全量重训后部署模型的性能。

后续泛化能力评价必须使用新的、未参与本次训练和参数选择的独立数据。

## 发布验收

训练程序在临时同级目录中完成三个模型的训练、回读、43 维顺序校验、六类集合校验、概率有限性与归一化校验、SHA-256 记录，全部通过后才原子发布到 `models/catboost43_v3/`。已存在的部署目录不会被覆盖。
