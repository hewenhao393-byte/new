# 水泵故障诊断软件验收摘要

## 1. 当前软件主流程

输入振动文件 -> 原始信号读取 -> 信号质量检查 -> 正式预处理 -> 分窗 -> 21维正式特征提取 -> BP 六分类推理 -> 概率融合 -> 可视化整理 -> 报告展示与 Word 导出

## 2. 已完成模块

- 正式六分类推理契约
- 单文件正式推理
- 统一 visualization 数据
- Streamlit 单文件诊断与报告页
- CLI 单文件诊断
- `SingleReportViewData`
- 单文件 Word 报告导出
- 统一报告导出服务
- 系统自检入口

## 3. 正式参数

- 目标采样率：`12000 Hz`
- 带通范围：`10~5000 Hz`
- 窗口长度：`2400`
- 滑动步长：`1200`
- 包络频带：`2000~5000 Hz`
- 小波包：`db6` 三层
- 六类标签顺序：正常 / 转子不平衡 / 联轴器不对中 / 松动 / 轴承故障 / 汽蚀

## 4. 当前测试结果

当前稳定验收版本测试结果：

- `135` 项自动化测试通过
- 包含单元测试、UI 逻辑测试、CLI 测试、导出测试和端到端验收测试

以最近一次完整验证为准。

## 5. 已具备能力

- 单文件正式六分类诊断
- 六类概率分布展示
- 窗口级预测分布展示
- 时域、频谱、包络谱、小波包能量占比展示
- 单文件 Word 报告导出
- CLI 导出 Word 报告
- 系统部署自检

## 6. CLI 能力

- 单文件正式诊断
- JSON 结果输出
- JSON/CSV 摘要导出
- Word 报告导出
- 系统自检

## 7. 当前未覆盖能力

- batch Word 报告
- PDF 报告
- batch 可视化报告
- 未知泵型和明显不同采集条件下的泛化验证

## 8. 旧流程隔离说明

以下内容仅作实验追溯，不得作为正式软件推理入口：

- 旧 `4096/2048` 配置
- 旧 `db4` 小波配置
- 旧六分类标签顺序
- 旧实验训练脚本与探索脚本

## 9. 后续建议

- 如需继续扩展，优先补充 batch 报告服务层
- 如需正式交付，再增加 PDF 报告与模板化导出
- 如需增强可靠性，补充更多现场数据下的泛化验收

## 10. 当前固定演示样本

- 主演示样本：`Motor-4 / 70 / 汽蚀 / 出口汽蚀5`
- 说明：在指定候选范围内，未找到 `warning_count` 更少的样本，因此最终选择了置信度、概率差和窗口一致率更优的汽蚀样本作为主演示。
