# 水泵振动单通道43维特征与两种划分数据集设计

## 目标与边界

从20 kHz原始振动数据重新构建CH3、CH4、CH5三个单通道43维特征表，并分别实现文件级划分和文件内连续时间块划分。两种划分的产物彻底隔离，不训练模型，不生成129维拼接表，不修改正式软件推理链路，不覆盖任何既有特征、模型或实验结果。

下一阶段模型算法已确认为CatBoost，但不在本设计的实现范围内。

## 原始记录和三通道对齐

每个通道CSV含有多个12秒数据列。一条独立物理采集记录定义为：

```text
record_id = 设备 + 转速目录 + 工况目录 + 信号列号
group_id = record_id
```

程序将沿用现有审查清单中的稳定字符串形式，例如：

```text
Motor-2::100::正常状态1::0
```

工况目录相同且列号相同的CH3、CH4、CH5视为同一条记录。三个通道必须同时存在，样本数、时间轴和列号必须一致。整个包含19列的CSV不视为单个 `file_id`。

## 数据来源与元数据

三通道配对和六类标签以现有 `实验结果/三通道融合_数据审查/record_pairs.csv` 为基础。该清单已包含1845条合格记录，分属正常、转子不平衡、联轴器不对中、松动、轴承故障和汽蚀六类。

`测量工况总表.xlsx` 用于补充实测RPM、severity、condition和state。匹配规则必须显式、唯一且可审计。对于无法唯一匹配的字段，保留原始目录状态并将未知字段留空，不推测轻度、中度或重度。元数据匹配失败须进入审计报告，不能静默填充。

## 信号预处理

每条 `record_id` 的每个通道独立执行以下固定处理：

1. 检查NaN、Inf、全零、异常短记录、大量连续相同值、明显ADC削顶和明显采集断点，输出 `quality_flag` 和 `quality_reason`。高峰值、高峭度和冲击本身不作为删除理由。
2. 对完整20 kHz记录去均值。
3. 使用 `scipy.signal.resample_poly(x, up=3, down=5)` 重采样至12 kHz。
4. 使用四阶Butterworth SOS和 `sosfiltfilt` 对完整重采样记录执5–5000 Hz零相位带通滤波。
5. 在滤波完成后应用指定划分，然后在各自允许的连续区域内滑窗。

固定参数为：原始采样率20000 Hz、目标采样率12000 Hz、窗长4800点、步长2400点、分析频带5–5000 Hz、随机种子2026。

## 文件级划分

文件级划分的最小分组单位为 `record_id`，不是物理CSV路径。程序将生成约80% `train_dev` 和20% `test` 的固定划分，在不拆分记录的前提下尽量兼顾标签、设备、转速和状态。

同一 `record_id` 的三个通道及全部滑窗必须整体进入同一侧。划分保存为 `file_split.csv`。如果该文件已存在，程序必须校验记录集合和配置后直接复用，不得重新随机划分。

完整记录在预处理后以4800点窗长和2400点步长滑窗；不足4800点的尾部直接舍弃，不补零。

## 时间块划分

每条12秒 `record_id` 在完整预处理后划分为70% train、5% guard和25% test。使用固定种子2026为每条记录稳定选择“测试在前”或“测试在后”，并把12 kHz样本索引作为权威边界写入 `temporal_split.csv`。

CH3、CH4、CH5对同一 `record_id` 必须使用完全相同的train、guard和test边界。guard不产生窗口。train和test分别独立滑窗，任何窗口都不得跨越区域边界。

train内部建立1.6秒连续块（19200点），末尾保留实际剩余块；只有能完整容纳4800点窗口的块才产生窗口。训练窗口不得跨越 `train_block_id` 边界，以便下一阶段使用分组交叉验证。

## 43维单通道特征

三个通道使用完全相同的特征名、顺序和实现：

- 9个时域特征：RMS、标准差、峰峰值、偏度、Pearson普通峭度、峰值因子、脉冲因子、裕度因子和波形因子。
- 10个阶次与谐波特征：按转频计算0.5X、1X、1.5X、2X、2.5X、3X、4X和5X附近能量及指定比值。
- 4个频谱形状特征：归一化频谱熵、频谱平坦度、频谱重心和频谱带宽。
- 5个频带能量特征：5–300 Hz、300–1000 Hz、1000–3000 Hz、3000–5000 Hz能量占比及高低频能量比。
- 9个小波包特征： `db6` 三层8个末层节点能量占比和归一化小波包能量熵。
- 6个包络特征：1000–5000 Hz高频带包络的时域峭度、峰值因子，以及5–500 Hz包络谱熵、主峰能量占比、主峰集中度和主峰数。

时域和小波包特征使用未加窗片段；FFT、阶次、频谱形状、频带能量和包络频谱使用Hann窗。阶次积分和包络峰积分统一采用目标频率±2.5 Hz。相邻频带采用半开区间，最后一段包含5000 Hz，防止边界频点重复计数。所有除法都使用 `EPS = 1e-12`。

## 输出与可重复性

产物写入新目录 `实验结果/单通道43维_两种划分_20260920/`，结构为：

```text
file_split/
  file_split.csv
  features_ch3.csv
  features_ch4.csv
  features_ch5.csv
  dataset_summary.csv
  quality_audit.csv
  leakage_audit.json
temporal_split/
  temporal_split.csv
  features_ch3.csv
  features_ch4.csv
  features_ch5.csv
  dataset_summary.csv
  quality_audit.csv
  leakage_audit.json
```

每个特征行至少包含 `record_id`、`group_id`、`window_id`、`split_mode`、`split`、`channel`、`motor`、`rpm`、`speed_percent`、`condition`、`state`、`severity`、`label`、`start_sample`、`end_sample`、`start_time`、`end_time`、`train_block_id`、`quality_flag`、`quality_reason` 和43个特征列。

程序保存配置摘要、输入清单哈希和划分哈希。输出目录已存在且与配置不匹配时必须停止，不得静默覆盖。运行中间结果采用新的checkpoint子目录，不删除任何旧文件。

## 质量和泄漏验证

自动验证包括：

1. 每个窗口恰好43个特征，且特征中无NaN和Inf。
2. CH3、CH4、CH5的 `(record_id, split, window_id, start_sample, end_sample)` 键完全一致，标签和转速一致。
3. 文件级 `train_dev record_id ∩ test record_id = ∅`。
4. 时间块train/test原始时间范围无重叠，guard至少0.6秒，任何窗口都不进入guard或跨越区域边界。
5. 时间块训练窗口不跨越 `train_block_id` 边界。
6. 频带能量划分无边界重复，谱熵在合理范围，8个小波包能量占比之和在数值容差内等于1。
7. 按类别、记录、通道和split统计窗口数，检查RPM缺失和越界阶次。
8. 分别重新读取六张最终特征表，校验列顺序、行数、唯一键、数值有限性和三通道对齐。

## 测试策略

实现采用测试驱动开发。单元测试覆盖记录ID构造、工况表匹配、质量标记、重采样和滤波长度、区域内滑窗、43维特征数值性质、两种划分的稳定性及泄漏阻断。集成测试使用少量真实记录生成六张小型特征表并执行完整审计。全量运行前先执行限量端到端验证，全量运行后再执行最终表回读验收。
